# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Diamon, please report it privately through GitHub's
"Report a vulnerability" button on the Security tab of this repository rather than opening a public issue.

Diamon is a fork of [Wallos](https://github.com/ellite/Wallos). If the vulnerability also affects the original
Wallos code, please report it to the Wallos maintainer as well, at [wallos@henrique.pt](mailto:wallos@henrique.pt).

## Supported Versions

This project is currently supported with security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| main    | :white_check_mark: |
| 1.x.x   | :x:                |

## Security Measures

We take security seriously and am working on ways to implement security measures to protect the project.

What is being done currenty:
- Periodically scan the docker image for vulnerabilities with trivy.

## Reporting a Security Concern

If you have any security concerns or questions regarding the security of Diamon, please use the private
vulnerability reporting described above.

## Responsible Disclosure

We kindly request that you follow responsible disclosure practices and give us reasonable time to address any reported vulnerabilities before making them public.
